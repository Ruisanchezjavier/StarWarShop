# StarWarShop

A fully functional e-commerce web application built with JavaScript — themed around the Star Wars universe.

## What it does

- Browse a product catalog of Star Wars items
- Add products to a shopping cart
- Update quantities and remove items
- View order total in real time
- Clean, responsive UI

## Built with

- JavaScript (ES6+)
- React
- HTML5 & CSS3
- REST API integration

## Why this project

Built to demonstrate core e-commerce functionality — product listing, cart management, and state handling — skills directly applicable to real-world online store development.
